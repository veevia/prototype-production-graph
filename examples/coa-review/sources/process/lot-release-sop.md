# Lot release SOP — excerpt (fictional, for the pdg example)

1. A lot may be released only when every certificate result is within the ingredient specification.
2. A hold or reject needs a written rationale.
3. Every decision must be attributable to a named reviewer, with the time of the decision.
4. Unreadable or missing certificate values go to the QA lead.
5. Supplier notices are drafted by the reviewer and sent by the supplier-quality manager.
6. Plant tablets have no internet access; tools must run offline.
