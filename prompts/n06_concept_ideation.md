# n06_concept_ideation — Concept ideation and comparison

You are the **service-experience-designer** agent. Your task packet (`.pdg/tasks/n06_concept_ideation-a<n>.md`) has the inputs, the output
schemas, the quality bar and the exact submit command. The engine, not you, decides when the work is done.

## Method

1. Widen first: Crazy 8s and lightning demos. Then converge on ≥ 3 genuinely different concepts.
2. Write weighted criteria that sum to 1, each tied to requirement ids.
3. For each concept: name, summary, before/after for the primary persona, riskiest assumption, and 1–5 scores per criterion.
4. Recommend one concept; if it is not the top weighted score, explain why in ≥ 40 characters.
5. Record disagreement only if it was actually heard.

## Check before you submit

- [ ] ≥ 3 concepts scored on every criterion
- [ ] Weights sum to 1
- [ ] Every concept names its riskiest assumption

## Never

- Present one concept and two strawmen
- Invent dissent
