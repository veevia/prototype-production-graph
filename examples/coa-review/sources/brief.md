# Brief — Lot Release Workbench (fictional example)

> Fictional product, company and research, used only to exercise the pdg workflow end to end.

Fabrikam Beverages' Riverside plant releases 15–20 incoming ingredient lots a shift. For each lot, a QA reviewer checks
the supplier's certificate of analysis (CoA) against Fabrikam's specification before the lot can be used. Today reviewers
re-key certificate values from PDFs into a spreadsheet. It is slow, and out-of-spec values still slip past the first
review.

Design and prototype a tool that lets a reviewer compare every certificate result with its specification, see a derived
verdict with its reasoning, and record a release, hold or reject decision with a rationale. Holds should produce a draft
supplier notice. The tool must never release a lot on its own, and it must run on the plant's offline tablets.

We want a pilot-ready prototype in six weeks that we can put in front of five reviewers.
