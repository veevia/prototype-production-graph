# Fabrikam Quality UI — design guide excerpt (fictional, for the pdg example)

- Typeface: the platform UI font (Segoe UI on Windows tablets); no web fonts (tablets are offline).
- Colour: accent blue #0B5CAD for actions and links; neutral ink #1B1F24 on white and a light canvas #F6F7F9.
- Status colours: green #1D6B37 on #E7F4EC (pass), amber #7A4F00 on #FFF3D6 (attention), red #B3261E on #FDECEB (fail).
  Red is reserved for failures; status is always icon + text + colour.
- Spacing on a 4 px scale; radii 4 px (controls) and 8 px (panels); pill chips.
- Touch targets 44 px on tablets; visible focus ring; no gradients.
